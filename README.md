# 🌐 Proyecto Intermodular — Gestión de Voluntariado (DAM 1º)

Proyecto final del módulo intermodular realizado en **DAM 1º** en Cuatrovientos.  
El objetivo fue diseñar y desarrollar una **aplicación web completa** para la gestión de voluntariado en un centro, utilizando únicamente **HTML, CSS y JavaScript**, junto con el framework **Bulma**.

Este proyecto marca uno de mis primeros desarrollos web completos y estructurados, con varias páginas, flujos de usuario y funcionalidades reales.

---

## 🚀 Funcionalidades principales

### 👥 Gestión de voluntariado
- Alta y administración de voluntarios.
- Páginas separadas para vista de usuario y administrador.
- Control básico de datos del voluntario.

### 📁 Gestión de proyectos
- Listado visual de proyectos activos.
- Detalles y descripción de cada proyecto.
- Organización de contenido por categorías y páginas internas.

### 📰 Sistema básico de noticias
- Sección de noticias generales.
- Página para administradores (añadir o editar contenido).

### 🎨 Diseño y UI/UX
- Diseño responsive con **Bulma CSS**.
- Uso de layouts reutilizables.
- Organización del contenido visual y navegación clara.

---

## 🛠️ Tecnologías utilizadas

- **HTML5**  
- **CSS3** (incluyendo Bulma)  
- **JavaScript**  
- Metodología por **Sprints**  
- Documentación en Word y diagrama en `.mdj`
